# semble

**Fast code search for agents** — semantic code search optimized for AI agent consumption. Find code by meaning, not just text.

## What This Gives You

- **Semantic search** — find code by what it does, not just what it contains
- **Agent-optimized** — structured results designed for AI agent consumption
- **Fast indexing** — incremental indexing that keeps up with code changes
- **Multi-language** — parses and indexes code across programming languages

## How It Fits

Code intelligence tool for the SuperInstance agent fleet. Used by `warp` for code-aware AI assistance and by `plato-training` for code evaluation.
